# Kairos - “Be there. Be now.”

> A role-based workspace application featuring dedicated admin and employee environments.

Kairos is a streamlined internal management tool. It handles authentication, role-based routing, and separates overarching operational controls (Admin) from daily task execution (Employee) into two distinct, secure dashboards.

## Features

- 🔐 **Role-Based Access Control (RBAC):** Secure routing and protected endpoints based on user roles.
- 📊 **Admin Dashboard:** Centralized view for managing workflows, users, and overarching data.
- 💻 **Employee Dashboard:** Clean, focused interface for daily tasks and personal metrics.
- ⚡ **Responsive UI:** Fully mobile-responsive and accessible component design.
- 🔒 **Secure Auth:** Integrated session management and backend protection.

## Tech Stack

- **Frontend:** Next.js, React, Tailwind CSS
- **Backend & Auth:** Next.Js, Prisma 7
- **Database:** PostgreSQL, Neon.tech

## What to expect unique:
- **Dynamic QR Code** - For attendance login, The QR code would be generated on the website and a scanner would be placed at the entrance where the dynamic qr code will be scanned. The backend is already prepared only to be implemented on the frontend which wasnt possible due to time constraints.
